# 官网三维地图运行文件

线上入口：[pkuidv.com/tactical-friend/3d/](https://pkuidv.com/tactical-friend/3d/) 与 [pkuidv.com/zhanshuyanlian/3d/](https://pkuidv.com/zhanshuyanlian/3d/)。各自的二维入口切换三维、返回二维时保留相同路径前缀，浏览器显示具体地图文件名，不显示版本哈希。

本目录包含 31 个公开运行文件：十个固定地图加载页、十个带内容哈希的地图运行页、地图列表、版本信息、六个原有辅助文件和三个加载辅助文件。地图模型沿用已公开的资源快照；工具同时包含端点通行检查、防穿模寻路、漫游出生检查、俯瞰移动速度设置和下载/准备进度提示。二维切换只同步对应地图的测距起终点，无法通行的原始选点会明确提示，不自动移动坐标。

当前网页运行版为 `0.17.0-preview.10`：包含搏命下椅 20 秒范围、选起点查可挂椅子、选目标椅子查挂人起点范围，以及挂椅耗时极值候选。椅子组合与地下室位置可选，牵气球路径禁止翻窗，范围和选定路线支持二维与三维查看。挂人色带标为 3 次、2 次、1 次、不可再放，90%–100% 挣扎进度单列淡黄色风险区；平面页眉「地图图例 → 颜色说明」统一控制搏命和挂人图例，默认关闭。极值点按到最近可用椅子的预计挂椅时间降序编号，1 号表示当前配置下本次找到的最难挂椅候选；极值点图例说明形状与排名。颜色说明框支持拖动标题、右下角缩放、键盘调整、复位和关闭，缩小后可滚动；导出图片保留显示状态和框的位置。边角候选可能受显示筛选或未确认挂椅通路影响，不把无路线样本按无穷大排名。落地僵直按统一的 1/3 秒模型计入时间，放下次数按进度预算估算，未额外模拟下放、重新牵起及随机摇晃耗时。

本候选版本以 Recast/Detour + Funnel 生成路线，仍逐段核验原始导航面、授权窗板动作、完整人物胶囊体和当前激活物件。窄道或候选无法通过核验时，按剩余预算尝试原求解器，并在结果中记录回退。时间目标比较有限候选的角色和天赋耗时；不承诺全局最短或全局最快。组件及 WebAssembly 随 worker 内嵌，无额外 CDN 下载。首次上线须先安装三维 WebAssembly CSP；具体配置、预检与发布流程见下方发布说明。

二维应用及本目录由本仓库的 `main` 分支统一检查、打包和发布。发布构建不读取私有仓库，也不需要私有仓库凭据。固定入口重新验证并保留查询参数及坐标片段，大运行文件按最终内容哈希长期缓存；加载页核对其字节数、完整 SHA-256 和地图对应关系后才运行。

发布元数据的 `files`/`asset_urls` 保留 18 个稳定入口和原有辅助文件的兼容视图，`full_files`/`full_asset_urls` 列出全部 31 个文件。新增的十个地图运行页及三个加载辅助文件均作为已登记的 immutable 依赖发布；完整 31 项参与根发布清单、全局版本、文件与压缩哈希、路径和大小校验。CI 额外检查完整清单、加载绑定及解压内容一致性；既有接收器使用原有通用资源校验，并不解释新增的完整清单字段。详情见 [发布说明](../deploy/README.md)。

从仓库根目录运行 `npm run dev`，访问 `/tactical-friend/3d/`。地图运行文件需要通过 HTTP 加载。部署构建：`npm --prefix deploy run build`。

资源提取、格式解析、模型重建、缓存与研究材料留在内部工具库。更新地图时，由工具库生成并验证候选成品，只将本目录列出的运行文件作为公开发布变更提交。`deploy/scripts/maps3d.mjs` 使用精确文件清单，并校验地图、嵌入 worker、路径、大小及 SHA-256 绑定；额外文件、缺失文件和符号链接都会使构建失败。两份说明文档不进入发布包。旧 18 文件输入保留严格校验，供历史版本回滚。
